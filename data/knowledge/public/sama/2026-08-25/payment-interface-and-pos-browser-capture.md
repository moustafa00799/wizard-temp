# SAMA payment-interface and weekly-POS browser capture

## E-commerce payments interface

- Source URL: https://sama.gov.sa/en-US/MediaCenter/News/pages/news-1095.aspx
- Publisher: Saudi Central Bank (SAMA)
- Publication date shown in the public page: 7 Jul 2025
- Capture date: 2026-08-25

SAMA describes an ecommerce payments interface that integrates mada with global payment networks, uses unified technical specifications, provides centralized registration for banks and financial institutions, supports financing solutions for ecommerce businesses, and enables card tokenization. This is payment-infrastructure context only; it is not an ecommerce sales, market-share, audience, conversion, or advertising-performance measurement.

## Weekly POS reports page

- Source URL: https://www.sama.gov.sa/en-US/Statistics/Indices/Pages/POS.aspx
- Publisher: Saudi Central Bank (SAMA)
- Capture date: 2026-08-25

The page states that weekly POS reports track electronic payment activity through POS terminals across business activities and cities in Saudi Arabia, including transaction count, transaction value, and weekly percentage changes by activity and city. The page did not expose a downloadable table in the captured text, so no numerical row was created from it.

## Scope limitation

Both observations describe official payment infrastructure/report availability. Neither should be interpreted as ecommerce demand, product-level supply, advertising benchmark, market share, or competitor-performance evidence.
